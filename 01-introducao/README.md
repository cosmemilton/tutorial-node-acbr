# Aula 1 — Introdução

O pacote integra modelos Node.js ao motor ACBr compilado com Free Pascal/Lazarus. Segundo o README do SDK 0.1.2, é um projeto independente e não um produto oficial do ACBr; não depende de Delphi nem dos binários ACBr Pro.

Consumir o binário publicado é diferente de reconstruí-lo: neste tutorial o npm instala o motor da plataforma. Não é preciso instalar Free Pascal/Lazarus para executar os exemplos. Uma revisão própria do ACBr e a reconstrução do motor exigem ferramentas e validação adicionais, fora deste percurso.

Disponibilidade de compiladores gratuitos não elimina obrigações de licença. O SDK declara LGPL-2.1-or-later; dependências nativas têm avisos próprios. Antes de distribuir uma aplicação comercial, examine os componentes realmente distribuídos, seus avisos e os termos aplicáveis. Não se presume licença comercial necessária ou dispensa universal.

Fonte: [README e avisos do SDK](https://github.com/cosmemilton/acbr-node). A referência precisa desta entrega é o README incluído no pacote npm 0.1.2.
